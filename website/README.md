# EBENS GADGET UNIVERSE Website

This is the responsive web version of the EBENS GADGET UNIVERSE demo app.

The layout and user flow intentionally mirror the Android demo:
- Purple hero section
- Search
- Product categories
- Product cards and details
- Shopping cart
- Demo checkout
- Orders tab
- Account tab
- Store location and phone

Sample products/prices are demo data and should be replaced with the business's real inventory before production.

## Deploy

The repository includes a GitHub Pages workflow at:
.github/workflows/deploy-website.yml

Run **Deploy EBENS Gadget Universe Website** from GitHub Actions. If GitHub Pages asks for a source, choose **GitHub Actions** in the repository's Pages settings.
